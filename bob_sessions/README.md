# bob_sessions — Bob task session screenshots

This folder is a **required submission deliverable**: it proves IBM Bob IDE
was used to build the solution. Each team member uploads their own task
session summaries here.

## How to capture a session summary

1. In Bob IDE, open the chat interface and select **Tasks** to show the task list.
2. Select the task for this project (use **All** if your tasks span multiple workspaces).
3. Select the task header. A **task session consumption summary** is displayed.
4. Take a screenshot of the summary. Save as **PNG** for text clarity.

## Naming convention

```
triageops_taskNN_<short_description>_summary.png
```
